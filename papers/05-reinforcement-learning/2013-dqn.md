## 한 줄 요약

게임 화면 **픽셀만 보고** CNN으로 각 행동의 가치(Q값)를 예측하도록 학습시켜, 하나의 알고리즘으로 여러 아타리 게임을 사람 수준 가까이 플레이하게 만들었다.

## 왜 중요한가?

강화학습은 오래된 분야지만, 신경망과 결합하면 학습이 불안정해서 잘 되지 않는다고 여겨졌다. 또 기존 방법은 게임마다 사람이 특징(공의 위치 등)을 직접 뽑아 줘야 했다.
DQN은 **원시 픽셀 → 행동**을 하나의 신경망이 직접 학습하는 "딥 강화학습"을 처음으로 성공시켰다. 7개 게임 모두에 **같은 신경망 구조와 하이퍼파라미터**를 썼는데, 6개 게임에서 기존 방법을 넘었고 3개 게임에서는 사람 전문가보다 잘했다.
이 논문 이후 DeepMind는 AlphaGo(2016)로 이어졌고, 딥 강화학습은 로봇 제어, LLM 학습(RLHF)까지 퍼져 나갔다.

## 핵심 아이디어

### 1. Q-러닝 복습

- **Q(s, a)**: 상태 *s*에서 행동 *a*를 했을 때 앞으로 받을 총 보상의 기댓값
- Q값을 알면, 매 순간 Q값이 가장 큰 행동을 고르면 된다
- **벨만 방정식**: Q(s, a) = r + γ · max_a′ Q(s′, a′)
  - "지금 행동의 가치 = 바로 받는 보상 + (할인된) 다음 상태에서 할 수 있는 최선의 가치"
  - γ(감마)는 0~1 사이 할인율. 먼 미래 보상일수록 덜 중요하게 본다

Q-러닝은 예측한 Q(s, a)를 r + γ · max Q(s′, a′)에 가깝게 조금씩 고쳐 나간다.

### 2. Q값을 CNN으로 예측

상태가 게임 화면처럼 거대하면 모든 (상태, 행동) 쌍의 Q값을 표로 저장할 수 없다. 그래서 CNN이 화면을 입력받아 **가능한 모든 행동의 Q값을 한 번에** 출력하게 한다.

- 입력: 최근 4프레임(움직임 정보를 위해)을 84×84 흑백으로 줄여 쌓은 것
- 출력: 행동 개수만큼의 Q값 (예: 왼쪽, 오른쪽, 발사, …)

### 3. 경험 재생(experience replay) — 학습 안정화의 핵심

게임을 하면서 겪은 경험 (*s*, *a*, *r*, *s*′)을 **메모리에 저장**해 두고, 학습할 때는 메모리에서 **무작위로** 뽑아 쓴다.

| 문제 | 경험 재생의 효과 |
|---|---|
| 연속된 프레임은 서로 너무 비슷해서, 그대로 학습하면 한쪽으로 치우침 | 무작위로 섞어 데이터 간 상관관계를 깸 |
| 한 번 겪은 경험을 한 번만 쓰면 낭비 | 같은 경험을 여러 번 재사용 |

### 4. ε-탐욕(ε-greedy) 탐험

항상 Q값이 가장 큰 행동만 하면 새로운 전략을 발견할 수 없다. 확률 ε로는 무작위 행동을 하고, 학습이 진행될수록 ε를 줄인다.

## 읽는 팁

- 아홉 쪽 정도로 짧다. 강화학습 용어가 낯설다면 아래 Karpathy의 글이나 Spinning Up을 먼저 보자
- 먼저 읽기: 1장(서론), 4장(Deep Q-learning)과 **Algorithm 1**, 5장(전처리와 신경망 구조), 게임 중 Q값 변화를 보여 주는 그림
- 건너뛰어도 됨: 3장 관련 연구의 세부 내용
- 2년 뒤 Nature에 실린 [확장판(2015)](https://www.nature.com/articles/nature14236)은 49개 게임으로 실험을 넓히고 **타깃 네트워크**라는 안정화 기법을 추가했다. 지금 "DQN"이라고 하면 보통 이 버전을 가리키므로 함께 보면 좋다
