# Very Deep Convolutional Networks for Large-Scale Image Recognition (VGG, 2014)

| 항목 | 내용 |
|---|---|
| 저자 | Karen Simonyan, Andrew Zisserman (Oxford Visual Geometry Group) |
| 학회/저널 | ICLR 2015 |
| 링크 | [arXiv](https://arxiv.org/abs/1409.1556) |
| 난이도 | 🟢 |
| 사전 지식 | [AlexNet (2012)](2012-alexnet.md) |

## 한 줄 요약

**3×3 크기의 작은 필터만** 사용해 층을 16~19개까지 깊게 쌓으면, 단순한 구조로도 이미지 분류 성능이 크게 오른다.

## 왜 중요한가?

AlexNet 이후 "어떻게 하면 CNN을 더 잘 만들 수 있을까?"에 대해 VGG는 **"깊이가 중요하다"** 는 답을 명확하게 보여 줬다.
구조가 매우 단순하고 규칙적이라 이해하기 쉽고 구현도 쉬워서, 이후 몇 년간 이미지 특징 추출기의 표준처럼 쓰였다. 스타일 변환(style transfer)이나 생성 모델의 지각 손실(perceptual loss)처럼 "이미지의 특징을 비교"하는 곳에서는 지금도 사전학습된 VGG가 자주 쓰인다.
ILSVRC-2014에서 분류 부문 2위(1위는 GoogLeNet), 위치 추정 부문 1위를 차지했다.

## 핵심 아이디어

### 1. 큰 필터 하나 대신 작은 필터 여러 개

AlexNet은 첫 층에 11×11 같은 큰 필터를 썼다. VGG는 모든 합성곱층에 **3×3 필터만** 쓴다.

- 3×3 합성곱을 **2번** 쌓으면 5×5 영역을, **3번** 쌓으면 7×7 영역을 보는 효과가 난다
- 같은 영역을 보면서도 파라미터가 적다. 채널이 *C*개일 때 7×7 한 층은 49*C*²개, 3×3 세 층은 27*C*²개
- 층마다 ReLU가 들어가므로 **비선형성이 더 많아져** 더 복잡한 함수를 표현할 수 있다

### 2. 규칙적인 구조

```
[3×3 합성곱 × 2~4] → 최대 풀링 (해상도 절반)   ← 이런 블록을 5번 반복
→ 완전연결층 3개 → 1000개 클래스
```

- 풀링으로 해상도가 절반이 될 때마다 채널 수는 두 배(64 → 128 → 256 → 512)
- 깊이에 따라 11층(A)부터 19층(E)까지 여러 설정을 실험했다. 가장 유명한 것은 **VGG-16**(D)과 **VGG-19**(E)

### 3. 깊을수록 좋다 (단, 한계도 있다)

11층 → 13층 → 16층으로 깊어질수록 오류율이 줄었지만, 19층에서는 개선이 거의 멈췄다. 더 깊이 쌓을 때 생기는 학습의 어려움은 이듬해 [ResNet](2015-resnet.md)이 해결한다.

### 단점

VGG-16의 파라미터는 약 1억 3,800만 개로 매우 많고, 대부분이 마지막 완전연결층에 몰려 있다. 메모리와 연산량이 커서 지금 실서비스에서는 더 효율적인 구조를 쓴다.

## 읽는 팁

- 짧고 쉬운 논문이다
- 먼저 읽기: 2장(구조)과 **모델 설정 표**(A~E 설정을 나란히 비교한 표. 이 표 하나로 VGG를 이해할 수 있다), 2.3절(왜 3×3 필터인가)
- 그다음: 4장 결과 표에서 깊이에 따라 오류율이 어떻게 변하는지 확인
- 건너뛰어도 됨: 3장의 다중 스케일 학습·평가 세부 사항, 부록의 위치 추정 실험
