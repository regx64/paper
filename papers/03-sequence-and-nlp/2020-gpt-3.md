## 한 줄 요약

언어 모델을 **1,750억 파라미터**까지 키웠더니, 파인튜닝 없이 프롬프트에 **예시 몇 개만** 보여 줘도 새로운 과제를 수행하는 능력(**인컨텍스트 학습**, in-context learning)이 나타났다.

## 왜 중요한가?

GPT-3는 "모델을 키우면 질적으로 새로운 능력이 생긴다"는 것을 극적으로 보여 줬다.
과제마다 데이터를 모아 파인튜닝할 필요 없이, **프롬프트에 지시와 예시를 적는 것만으로** 모델을 원하는 대로 쓸 수 있게 되었다. 이른바 "프롬프트 엔지니어링"이 여기서 시작되었고, GPT-3는 API로 공개되어 수많은 응용 서비스를 낳았다.
ChatGPT는 GPT-3 계열 모델을 [InstructGPT](../06-large-language-models/2022-instructgpt.md) 방식으로 추가 학습한 것이다.

## 핵심 아이디어

### 1. 인컨텍스트 학습: 가중치를 바꾸지 않고 배우기

논문의 핵심 그림이 세 가지 방식을 비교한다. 모두 **모델의 가중치는 전혀 바뀌지 않는다.**

```
제로샷 (zero-shot):  영어를 프랑스어로 번역하세요:
                     cheese =>

원샷 (one-shot):     영어를 프랑스어로 번역하세요:
                     sea otter => loutre de mer
                     cheese =>

퓨샷 (few-shot):     영어를 프랑스어로 번역하세요:
                     sea otter => loutre de mer
                     peppermint => menthe poivrée
                     plush giraffe => girafe peluche
                     cheese =>
```

모델은 프롬프트 안의 예시만 보고 "아, 이런 과제구나"를 알아채 다음을 이어 쓴다. 기존 **파인튜닝**은 과제별 데이터로 가중치를 업데이트하는 것이라는 점과 대비된다.

### 2. 규모가 핵심

| 항목 | GPT-2 | GPT-3 |
|---|---|---|
| 파라미터 | 15억 | **1,750억** (약 100배) |
| 층 | 48 | 96 |
| 학습 토큰 | — | 약 3,000억 |

구조는 GPT-2와 거의 같다. 논문은 1억 2,500만부터 1,750억까지 **8가지 크기**의 모델을 학습시켜 비교했는데, **모델이 클수록 퓨샷 성능이 제로샷보다 훨씬 크게 좋아졌다.** 즉, 인컨텍스트 학습 능력 자체가 규모에 따라 커진다.

학습 데이터는 필터링한 Common Crawl(웹 문서)을 중심으로, WebText2, 책 데이터, 위키백과를 섞었다. 품질이 높은 데이터는 더 자주 보도록 샘플링 비율을 조정했다.

### 3. 결과와 한계

- 번역, 질의응답, 빈칸 채우기 등 여러 과제에서 퓨샷만으로 파인튜닝된 모델에 근접하거나 일부는 넘어섬
- GPT-3가 쓴 짧은 뉴스 기사를 사람이 기계가 쓴 것인지 구별하는 정확도는 **약 52%**, 거의 찍는 수준
- 반면 한 단어가 두 문장에서 같은 뜻으로 쓰였는지 판단하는 과제(WiC), 자연어 추론(ANLI), 일부 독해 과제에서는 여전히 약했다
- 논문 스스로 한계(긴 글에서의 반복과 모순, 상식 물리 추론의 약점, 막대한 학습 비용)와 사회적 영향(악용, 편향, 에너지 사용)을 길게 논의한다

## 읽는 팁

- **본문만 40쪽이 넘는 매우 긴 논문**이다. 전부 읽을 필요 없다
- 먼저 읽기: 1장(서론)과 앞쪽 그림들(인컨텍스트 학습 개념, 모델 크기별 성능 그래프, 제로·원·퓨샷 비교 그림), 2장(접근 방법)과 모델 크기 표, 학습 데이터 구성 표
- 그다음: 5장(한계), 6장(사회적 영향). LLM의 문제점을 이해하는 데 좋다
- 건너뛰어도 됨: 3장 각 벤치마크 결과의 세부 내용(관심 있는 과제만 골라 보기), 4장(데이터 오염 측정), 부록
- 3장에서는 "뉴스 기사 생성"과 "산술 연산" 결과가 흥미롭다
