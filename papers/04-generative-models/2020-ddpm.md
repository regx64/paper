## 한 줄 요약

이미지에 노이즈를 조금씩 더해 완전한 노이즈로 만드는 과정을 거꾸로 되돌리도록 신경망을 학습하면, **순수한 노이즈에서 시작해 이미지를 만들어 낼 수 있다.**

## 왜 중요한가?

Stable Diffusion, DALL·E 2, Midjourney 같은 이미지 생성 AI의 **기반이 되는 논문**이다.
디퓨전 모델의 아이디어 자체는 2015년에 [이미 나왔지만](https://arxiv.org/abs/1503.03585), 이미지 품질은 GAN에 못 미쳤다. DDPM은 학습 목표를 "**노이즈 예측**"이라는 아주 단순한 형태로 바꿔, GAN에 견줄 만한 품질을 처음으로 보여 줬다(CIFAR-10 FID 3.17).
GAN과 달리 학습이 안정적이고 모드 붕괴가 적어, 이후 이미지 생성의 주류가 디퓨전으로 넘어가는 계기가 되었다.

## 핵심 아이디어

### 1. 순방향 과정(forward process): 노이즈 더하기 — 학습 불필요

깨끗한 이미지 *x*₀에 아주 작은 가우시안 노이즈를 *T* = 1000번 조금씩 더한다. 마지막 *x*_T는 거의 순수한 노이즈가 된다.

```
x₀ (원본) → x₁ → x₂ → … → x₁₀₀₀ (순수 노이즈)
```

이 과정은 정해진 공식일 뿐 학습할 것이 없다. 게다가 중간 단계를 하나씩 거치지 않고도 **임의의 단계 *t*의 노이즈 이미지를 한 번에** 만들 수 있다.

> *x*_t = √ᾱ_t · *x*₀ + √(1 − ᾱ_t) · ε  (ε는 표준 정규분포 노이즈, ᾱ_t는 *t*가 커질수록 0에 가까워지는 미리 정한 값)

즉, *x*_t는 "원본을 조금 남기고 노이즈를 섞은 것"이다.

### 2. 역방향 과정(reverse process): 노이즈 걷어내기 — 신경망이 학습

신경망 ε_θ(*x*_t, *t*)에게 "노이즈 섞인 이미지 *x*_t와 단계 *t*를 줄 테니, **섞인 노이즈 ε가 무엇이었는지 맞혀 봐**"라고 학습시킨다.

> 손실 = ‖ ε − ε_θ(*x*_t, *t*) ‖²  (실제 노이즈와 예측한 노이즈의 차이)

학습 절차(논문의 Algorithm 1)는 놀라울 만큼 단순하다.

1. 학습 이미지 *x*₀를 하나 고른다
2. 단계 *t*를 1~1000 중 무작위로 고른다
3. 노이즈 ε를 뽑아 위 공식으로 *x*_t를 만든다
4. 신경망이 ε를 맞히도록 경사 하강법으로 한 걸음 학습한다

### 3. 생성(샘플링)

순수한 노이즈 *x*₁₀₀₀에서 시작해, 신경망이 예측한 노이즈를 조금씩 빼면서 *x*₉₉₉, *x*₉₉₈, … , *x*₀까지 1,000단계를 거꾸로 내려온다(논문의 Algorithm 2).

> 비유: 조각가가 대리석 덩어리(노이즈)에서 조금씩 깎아 내며 조각상(이미지)을 드러내는 것과 비슷하다.

### 4. 신경망 구조

입력과 출력이 같은 크기의 이미지여야 하므로 **U-Net**을 사용한다(잔차 블록과 셀프 어텐션 포함). 단계 *t*는 트랜스포머의 위치 인코딩과 같은 방식으로 벡터로 바꿔 넣는다.

### 한계

1,000단계를 거쳐야 하므로 **생성이 느리다.** GAN은 한 번에 이미지를 만든다. 이 문제를 줄이는 것이 후속 연구(DDIM 등)의 주요 주제가 되었다.

## 읽는 팁

- 수식이 많아 처음에는 어렵게 느껴진다. **수식 유도는 건너뛰고 Algorithm 1(학습)과 Algorithm 2(샘플링) 박스부터 보자.** 이 두 박스가 논문의 핵심을 거의 다 담고 있다
- 먼저 읽기: 1장(서론), 순방향·역방향 과정을 보여 주는 그래프 모델 그림, 3.2절(역방향 과정)과 3.4절(단순화된 학습 목표), 두 알고리즘 박스, 생성 샘플 그림
- 건너뛰어도 됨: 2장의 변분 하한(variational bound) 유도, 3.3절의 데이터 스케일링과 디코더 세부 사항
