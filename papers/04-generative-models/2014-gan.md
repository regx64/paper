## 한 줄 요약

가짜를 만드는 **생성자(Generator)** 와 진짜·가짜를 가려내는 **판별자(Discriminator)** 를 서로 경쟁시키며 학습하면, 생성자가 진짜 같은 데이터를 만들게 된다.

## 왜 중요한가?

그전까지 이미지를 "생성"하는 모델은 복잡한 확률 계산이 필요해 다루기 어려웠다. GAN은 **두 신경망의 게임**이라는 직관적인 틀로 이 문제를 우회했고, 역전파만으로 학습할 수 있었다.
이후 몇 년간 GAN은 이미지 생성 연구의 중심이었고, 실제 사람과 구별하기 어려운 얼굴 사진을 만드는 StyleGAN까지 발전했다. 지금은 이미지 생성의 주류가 [디퓨전 모델](2020-ddpm.md)로 넘어갔지만, "적대적 학습"이라는 아이디어는 여전히 여러 곳에서 쓰인다.

## 핵심 아이디어

### 위조지폐범과 경찰

논문에 나오는 비유가 가장 이해하기 쉽다.

- **생성자 G (위조지폐범)**: 무작위 노이즈 *z*를 받아 가짜 데이터 G(*z*)를 만든다. 목표는 경찰을 속이는 것
- **판별자 D (경찰)**: 데이터를 받아 그것이 진짜일 확률 D(*x*)를 출력한다. 목표는 진짜와 가짜를 정확히 가려내는 것

둘이 번갈아 실력을 키우다 보면, 결국 위조지폐가 진짜와 구별할 수 없을 정도가 된다.

### 목적 함수

> min_G max_D  E[log D(*x*)] + E[log(1 − D(G(*z*)))]

- 첫 번째 항: 진짜 데이터 *x*에 대해 D는 1에 가까운 값을 내고 싶다
- 두 번째 항: 가짜 데이터 G(*z*)에 대해 D는 0에 가까운 값을 내고 싶고, G는 반대로 D가 1을 내게 만들고 싶다
- D는 이 값을 **최대화**, G는 **최소화**하려고 한다 → 미니맥스 게임

### 이론적 결과

논문은 이 게임의 최적점에서 **생성자의 분포가 실제 데이터 분포와 정확히 같아지고**, 판별자는 모든 입력에 1/2(반반)을 출력한다는 것을 증명한다. 경찰이 더 이상 구별할 수 없는 상태다.

### 실전 팁 (논문에 이미 있음)

학습 초반에는 G가 형편없어서 D가 쉽게 이긴다. 이때 log(1 − D(G(*z*)))를 최소화하면 기울기가 거의 0이 되어 G가 배우지 못한다. 그래서 실제로는 **log D(G(*z*))를 최대화**하도록 바꿔 학습한다.

### 한계

- 학습이 불안정하다. 두 신경망의 균형이 깨지기 쉽다
- 생성자가 판별자를 속이는 몇 가지 결과만 반복해서 만드는 문제가 있다(이후 **모드 붕괴**, mode collapse라고 불림). 논문에서도 단점으로 언급한다

## 읽는 팁

- 먼저 읽기: 1장(서론의 위조지폐범 비유), 3장(적대적 네트워크)과 학습 과정을 1차원 분포로 보여 주는 그림, Algorithm 1(학습 절차)
