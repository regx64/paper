# Learning Representations by Back-propagating Errors (1986)

| 항목 | 내용 |
|---|---|
| 저자 | David E. Rumelhart, Geoffrey E. Hinton, Ronald J. Williams |
| 학회/저널 | *Nature* 323, 533–536 (1986) |
| 링크 | [Nature](https://www.nature.com/articles/323533a0) |
| 난이도 | 🟡 |
| 사전 지식 | [Deep Learning (2015)](2015-deep-learning.md), 미분의 연쇄 법칙 |

## 한 줄 요약

출력의 오차를 연쇄 법칙으로 **거꾸로 전파**해 각 가중치를 얼마나 고쳐야 하는지 계산하면, 은닉층이 있는 신경망도 학습할 수 있고, 은닉층은 문제 해결에 쓸모 있는 **내부 표현**을 스스로 만들어 낸다.

## 왜 중요한가?

1960년대 퍼셉트론은 입력과 출력 사이에 학습 가능한 층이 하나뿐이라, XOR처럼 간단한 문제도 풀 수 없다는 한계가 지적되었다. 은닉층을 넣으면 해결된다는 것은 알았지만, **은닉층의 가중치를 어떻게 학습할지**가 문제였다. 은닉 뉴런에는 "정답"이 없기 때문이다.
이 논문은 역전파(backpropagation)로 이 문제를 풀 수 있음을 보이고, 더 나아가 은닉층이 사람이 알려 주지 않은 **의미 있는 특징**을 학습한다는 것을 실험으로 보여 줬다. 오늘날 모든 딥러닝 모델은 이 알고리즘으로 학습된다.

> 참고: 역전파의 수학적 아이디어(자동 미분의 역방향 모드)는 이 논문 이전에도 여러 연구자가 독립적으로 제안했다. 이 논문의 기여는 이를 신경망 학습에 적용해 **은닉 표현 학습**이라는 관점으로 널리 알린 데 있다.

## 핵심 아이디어

### 1. 순전파(forward pass)

입력을 넣고 층마다 "가중합 → 비선형 함수(시그모이드)"를 계산해 출력을 얻는다. 출력과 정답의 차이로 오차 *E*를 계산한다(제곱 오차의 합).

### 2. 역전파(backward pass)

목표는 모든 가중치 *w*에 대해 ∂*E*/∂*w*(이 가중치를 조금 바꾸면 오차가 얼마나 변하는가)를 구하는 것이다.

- 출력층: 오차를 출력으로 미분하는 것은 쉽다
- 은닉층: 어떤 은닉 뉴런의 출력은 **다음 층의 여러 뉴런에 영향**을 준다. 그래서 다음 층 뉴런들의 오차 신호에 연결 가중치를 곱해 **모두 더하면** 그 은닉 뉴런의 오차 신호가 된다
- 이 계산을 출력층에서 입력층 방향으로 한 층씩 반복한다

핵심은 **연쇄 법칙**과 **중간 결과의 재사용**이다. 각 층의 오차 신호를 한 번만 계산해 아래층으로 넘기기 때문에, 가중치가 아무리 많아도 순전파와 비슷한 비용으로 모든 기울기를 얻는다.

### 3. 가중치 업데이트

Δ*w* = −ε · ∂*E*/∂*w* (경사 하강법). 논문은 이전 업데이트 방향을 일부 이어 가는 **모멘텀** 항도 함께 사용했다.

### 4. 은닉층이 배운 것

논문의 가계도 실험이 유명하다. 영국인 가족과 이탈리아인 가족, 구조가 같은 두 가계도를 학습시켰더니, 은닉 뉴런 중 일부가 "어느 나라 사람인가", "몇 세대인가" 같은 특징을 **스스로** 나타내게 되었다. 아무도 이런 특징을 알려 주지 않았다.

## 읽는 팁

- 4쪽짜리 짧은 논문이다. 다만 1980년대 표기법이라 처음에는 낯설 수 있다
- 먼저 읽기: 첫 문단(문제 제기), 역전파 수식 부분, 가계도 실험 그림과 은닉 뉴런 가중치 시각화
- 수식을 따라가기 어렵다면 아래 3Blue1Brown 영상이나 Karpathy의 micrograd 영상을 먼저 보고 돌아오자
- 직접 손으로 작은 신경망(입력 2, 은닉 2, 출력 1)의 기울기를 계산해 보면 이해가 확실해진다
