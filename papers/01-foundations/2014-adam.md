## 한 줄 요약

기울기의 **방향(평균)** 과 **크기(제곱의 평균)** 를 함께 추적해, 파라미터마다 학습률을 자동으로 조절하는 최적화 알고리즘이다.

## 왜 중요한가?

기본 확률적 경사 하강법(SGD)은 모든 파라미터에 같은 학습률을 쓰기 때문에, 학습률을 잘못 고르면 학습이 너무 느리거나 발산한다.
Adam은 **기본 설정값으로도 대부분의 문제에서 잘 작동**해서, 사실상 딥러닝의 표준 옵티마이저가 되었다. 지금도 대규모 언어 모델 학습에는 Adam의 변형인 AdamW가 가장 많이 쓰인다.

## 핵심 아이디어

Adam이라는 이름은 *Adaptive Moment Estimation*에서 왔다. 두 가지 "모멘트"를 추정한다.

| 이름 | 무엇을 추적하나 | 역할 |
|---|---|---|
| 1차 모멘트 *m* | 기울기의 이동 평균 | 공이 비탈을 굴러가듯 **관성(모멘텀)** 을 줘서 진동을 줄이고 꾸준히 나아감 |
| 2차 모멘트 *v* | 기울기 제곱의 이동 평균 | 기울기가 계속 큰 파라미터는 보폭을 줄이고, 작은 파라미터는 보폭을 키움 (RMSProp과 같은 아이디어) |

### 업데이트 규칙 (논문의 Algorithm 1)

매 단계 *t*마다, 기울기 *g*에 대해:

1. *m* ← β₁·*m* + (1 − β₁)·*g* — 기울기의 이동 평균
2. *v* ← β₂·*v* + (1 − β₂)·*g*² — 기울기 제곱의 이동 평균
3. *m̂* = *m* / (1 − β₁ᵗ), *v̂* = *v* / (1 − β₂ᵗ) — **편향 보정**
4. θ ← θ − α · *m̂* / (√*v̂* + ε) — 파라미터 업데이트

- 기본값: α = 0.001, β₁ = 0.9, β₂ = 0.999, ε = 10⁻⁸
- *m*을 √*v*로 나누기 때문에, 파라미터마다 기울기의 "평소 크기"에 맞춰 보폭이 정규화된다.

### 편향 보정은 왜 필요할까?

*m*과 *v*는 0에서 시작한다. 학습 초반에는 이동 평균이 0 쪽으로 치우쳐서 실제 값보다 작게 나온다. 3단계의 나눗셈이 이 치우침을 보정한다. *t*가 커지면 분모가 1에 가까워져 보정 효과는 사라진다.

## 읽는 팁

- 먼저 읽기: 2장의 Algorithm 1 (논문 전체에서 가장 중요한 부분), 2.1절(실제 보폭이 대략 α로 제한된다는 직관), 3장(편향 보정)
- 그다음: 6장 실험 그래프에서 SGD, AdaGrad, RMSProp 등과 비교하는 모습을 보자
- 건너뛰어도 됨: 4장 수렴 분석. 이 증명에는 이후 오류가 있다는 사실이 밝혀졌다([Reddi et al., 2018](https://arxiv.org/abs/1904.09237))
- 7장의 AdaMax는 참고로만 보면 된다
